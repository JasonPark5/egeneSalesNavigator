개인정보처리방침

최종 수정일: 2026-08-28

E-GENE™ Sales Navigator("이 앱")는 음성/텍스트로 목적지를 찾아 길찾기로 연결하고, Google Calendar를 연동하면 오늘 일정 기반 이동시간 브리핑과 음성으로 말한 일정을 캘린더에 등록해주는 개인/해커톤 검증용 프로젝트입니다. 이 페이지는 이 앱이 다루는 정보와 처리 방식을 설명합니다.

수집하는 정보

  • Google Calendar(calendar.events): 연동을 직접 선택한 사용자에 한해, 오늘 일정의 제목·시간·장소를 조회합니다. 또한 사용자가 음성으로 "일정 잡아줘"처럼 요청하면 사용자의 발화 내용을 바탕으로 새 일정을 사용자의 기본 캘린더에 생성합니다. 일정 생성은 사용자가 음성으로 직접 요청한 경우에만 일어나며, 앱이 임의로 일정을 만들거나 수정·삭제하지 않습니다.
  • 현재 위치(GPS): 브라우저 권한을 허용한 경우, 주변 장소 검색과 이동시간 계산에만 사용합니다.
  • 검색 발화/텍스트: 목적지를 찾기 위해 입력한 내용입니다.
  • 일정 등록 발화/텍스트: "내일 3시에 회의 잡아줘"처럼 음성으로 일정 생성을 요청한 경우, 그 발화 내용입니다.

정보 사용 방식

  • Calendar에서 가져온 일정 정보(제목·시간·장소)와 음성으로 요청한 일정 등록 발화는 이동시간 계산·음성 브리핑 생성·일정 정보(제목/날짜/시간/장소) 추출을 위해 AI(LLM) API에 전달될 수 있습니다 — 해당 목적으로만 쓰이고, 별도로 저장·재사용되지 않습니다.
  • 장소 검색을 위해 Kakao, 이동시간 계산을 위해 Naver 지도 API를 호출합니다.
  • 이 앱은 별도의 데이터베이스에 사용자의 일정 내용이나 검색 기록을 저장하지 않습니다. Google 계정 연동을 유지하기 위한 최소한의 인증 토큰만 브라우저의 HttpOnly 쿠키(서버가 관리, 자바스크립트로 읽을 수 없음)에 보관됩니다.
  • 수집한 정보를 광고, 프로파일링, 제3자 판매 목적으로 사용하지 않습니다.

연동 해제

앱 내 "연결 해제" 버튼을 누르면 저장된 인증 토큰이 즉시 폐기됩니다. 언제든 Google 계정 → 보안 → 타사 앱 및 서비스에서도 직접 연동을 해제할 수 있습니다.
